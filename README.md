## 🚀 About The Project

**NexaGesture AI** is an AI-based hand gesture recognition project developed using Python, OpenCV, and MediaPipe.

The project detects hand gestures through a camera and converts them into meaningful actions. It aims to provide a touchless and interactive experience using computer vision and gesture-based control.

---

## ✨ Features

* 🖐️ Real-time hand detection
* 🤖 AI-powered gesture recognition
* 🎯 Gesture-based action control
* 🎨 Virtual air canvas functionality
* 📷 Camera-based interaction
* ⚡ Real-time computer vision processing
* 🧩 Modular Python project structure

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/latha-rathod/NexaGesture-AI-Hand-Gesture-Recognition.git
```

### 2. Navigate to the Project

```bash
cd NexaGesture-AI-Hand-Gesture-Recognition
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Project

```bash
python main.py
```

> Ensure your camera is available and the required dependencies are installed.
